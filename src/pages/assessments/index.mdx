# Assessment

Three individual projects, worth 20%, 50%, and 30%, together making up the full 100% of the course
mark. Each project page carries its own brief, rubric, resources, and submission panel.

<AssessmentsGrid />

All three projects share one marking mechanism for the submitted-model component: the same public
evaluation layers, prohibited uses, separation validator, perplexity formula, and human-evaluation
process. See the [Evaluation Protocol](/assessments/evaluation-protocol/) for the complete rules.
